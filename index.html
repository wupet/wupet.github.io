Playground

RSA, step by step.

Generate primes searches upward from a random odd number, rejecting each candidate with Miller–Rabin until one survives — the same routine as my C++ build. Then it runs key generation, encryption and decryption below. Keep primes under about 106 so the numbers stay readable.

    Security review

    Where the camera leaks.

    Two findings from an IP-camera system sitting on a LAN you don't fully trust (think ARP spoofing, an old router). Both start the same way — something sensitive travels in the clear — and the fix is the same idea: encrypt it so an on-path observer gets nothing to use. Pick a finding, then toggle the fix and watch what changes. This is a defensive explainer: the weakness and the remedy, not an attack recipe.
